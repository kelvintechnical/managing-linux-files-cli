# Contributing to Managing Linux Files from the CLI

Thanks for wanting to contribute! This repo is a free, open Linux learning resource for people worldwide.

## How to Contribute

1. Fork the repo
2. Create a branch: `git checkout -b feature/your-topic`
3. Make your changes
4. Submit a Pull Request with a clear description

## What We Welcome
- Additional commands or flags not covered
- OS-specific notes (Debian, Arch, RHEL, Ubuntu)
- Shell scripting examples using redirection and pipes
- Fixes to commands or outdated content
- Translations to other languages

## Style Guide
- Use clear, beginner-friendly language
- Include code blocks for all commands
- Test every command before submitting
- Follow the existing section structure
